# android-ai-lab

Android 개발에 AI CLI를 통합하는 실험 저장소입니다.
프롬프트 엔지니어링, 하네스 구축, 자동화 워크플로우 등 다양한 실험을 통해
AI 보조 개발 방법론을 연구합니다.


## 기술 스택

- Language: Kotlin
- UI: Jetpack Compose
- Architecture: MVVM + Clean Architecture
- AI: Claude API
